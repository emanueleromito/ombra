# T0.8: recall of the encrypted pipeline on real embeddings

- **Command:** `modal run modal_app.py::recall` then `make results-pull`
- **Commit:** `8523b44`
- **GPU:** NVIDIA A100-SXM4-40GB
- **CUDA:** 12.6.3 image. Compiled for sm_80 and sm_86.
- **OpenFHE:** v1.6.1, openfhe-python 1.6.1.0 (pinned image)
- **Parameter set:** `m0_depth2` from `core/params/ckks_presets.json`, unchanged: HEStd_128_classic, ring dimension 16384, depth 2, scaling 50 bits, first modulus 60 bits, batch size 8192, FIXEDMANUAL, HYBRID (decision 0009)
- **Dataset:** `KShivendu/dbpedia-entities-openai-1M` (Hugging Face): OpenAI text-embedding-ada-002, 1536 dimensions. `ann-benchmarks.com/dbpedia-openai-1000k-angular.hdf5`, the first choice, returned HTTP 404. Stored on the Modal volume, not in the repository.
- **Subset:** 100,000 database vectors and 100 queries, disjoint seeded random subsets from 4 of the 26 shards, normalized to unit length. Ground truth: exact top-10 by numpy dot product over the subset. The dataset has no query split, so queries are other vectors from the same set.
- **Raw output:** `docs/plan/results/raw/results/t0.8-recall.json` (gitignored)

## Pipeline

Real end to end, in encrypted-DB mode: the client encrypts the column-packed database and centers with the public key; each query goes through `oq.encode_query`, GPU expansion and GPU search; then Relinearize, Rescale, an encrypted all-ones mask at level 1, and Rescale (level 2 asserted) in OpenFHE, then client decryption and top-k. Only public material goes to disk; the secret key stays in the client process.

Method, for the clustered settings: the encrypted scan runs once per query over all 100,000 vectors, and the decrypted scores are then restricted to the probed clusters' vectors. Stage 1 is a real encrypted run against encrypted cluster centers (one extra block per nlist). Faiss spherical k-means, 20 iterations, seed 20260108.

Re-ranking: the top 30 candidates by encrypted score are re-scored exactly with the plaintext vectors.

## Key findings

- **Encrypted full scan: recall@10 = 1.0**, and the encrypted top-10 equals the plaintext top-10 in all 100 queries.
- **CKKS noise costs no recall.** At every cluster setting, encrypted recall equals the plaintext recall of the same setting, to the 3 decimal places the 100 queries resolve. Using exact center scores with encrypted vector scores gives the same numbers. All loss comes from clustering.
- **Re-ranking changes nothing here.** It only reorders candidates, and the score noise is far below the score gaps that decide this ranking.
- Max score error: 2.618e-08 over the scan, 1.156e-08 over center scores (bound 1e-6).
