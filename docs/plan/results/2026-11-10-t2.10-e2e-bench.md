## Method

- Synthetic Gaussian mixture on the unit sphere (noise 0.7), d = 384, two filter fields of 8 values (400 columns per block; the filtered query sets both, 1 vector in 64 matches). No real data.
- Client-side spherical k-means (random init, 5 Lloyd iterations) into C = round(N / (2 * slots)) clusters, so a cluster is about 2 blocks (2 to 3 with imbalance) and a probe reads about 2 * nprobe blocks. slots = 8192 (`m0_depth2`), 4096 (`m0_compact_n8192`).
- Presets: `m0_depth2`, `m0_compact_n8192` (decision 0013 accepted). Sizes: 100,000 and 1,000,000.
- Blocks are encrypted by 16 forked client processes (public key) and inserted over gRPC one block per call. The server runs with `--insecure --no-auth`, GPU budget 24,000 MB, host budget 8,192 MB.
- Per query steps: client query encryption; stage 1 (query sent to center scores received: server expansion and scoring plus loopback transfer, as the API has no server-time field); client decrypt of stage 1 and choice of clusters; stage 2 (SearchChosen with nprobe = 2 to last SearchScores message; time of the first message also recorded); client parallel decrypt (T2.1 style pool, 16 processes) and band decode; merge of per-block top-10. The total is the sum of these six. A second round (clusters 3 and 4, same stream) follows only to get recall at nprobe 4; it is reported apart.
- Q queries (default 30) without filter and Q with filter, after 3 untimed warm-up queries of each kind. p50 = element n/2 of the sorted times, p95 = element int(0.95 n).
- Recall: recall@10 of the encrypted pipeline (no re-ranking) against the exact top-10 over the matching vectors, and the plaintext recall of the same clusters (exact centers scores and exact scores), at nprobe 1, 2, 4. Gap = encrypted minus plaintext; decision 0012 tolerance is 0.005. Full scan is not run (it would read the whole collection per query). With 30 queries this is a sanity check, not the rule's verdict (needs 1,000 queries on 2 datasets).
- GPU cache hit rate from /metrics is not available in this PR; only cache lines found in the server log are recorded (the server may log none).
- Storage: bytes on disk of the data directory (apparent and allocated) after ingest; ingest wall time, summed worker CPU time of encryption, summed upload call time.
- A run whose estimated disk (N * 400 * 96 B * 1.15, about 44 GB at 1M) exceeds the free disk writes `status: not_run` with the reason; nothing is shrunk silently.
