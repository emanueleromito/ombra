# T0.5: query expansion error on CPU (OpenFHE)

- **Command:** `modal run modal_app.py::test_openfhe --pytest-args "--expansion-large -k test_query_expansion"`
- **Commit:** `0b61edb`
- **Hardware:** Modal CPU-only container, no GPU. Requested `cpu=4.0`, `memory=16384`.
- **CUDA:** not used at run time (the drivers are compiled with the CUDA toolchain but make no CUDA calls)
- **OpenFHE:** v1.6.1, openfhe-python 1.6.1.0 (pinned image)
- **Parameter set:** `m0_depth2` from `core/params/ckks_presets.json`, unchanged: HEStd_128_classic, ring dimension 16384, depth 2, scaling 50 bits, first modulus 60 bits, batch size 8192, FIXEDMANUAL, HYBRID (decision 0009)
- **Pipeline:** the client multiplies q by 2^-L before encoding; no server-side EvalMult and no scale change (decision 0009, addendum). Synthetic seeded data, one run per d.

## Errors

Bound for both columns: 1e-6.

- **Leaf error:** max over all d leaves and all 8192 slots of |decrypted - q_j|.
- **Final-score error:** max over all 8192 slots of |decrypted - (stored @ q) * mask|, after expansion (0 levels), the T0.4 multiply-and-add with relinearize and rescale (1 level), and a ciphertext 0/1 mask with rescale (1 level). The test asserts level 2 on the result.
