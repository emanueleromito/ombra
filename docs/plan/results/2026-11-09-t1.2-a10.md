## Oracle

`ombra_search_gpu` feeds the same OpenFHE ciphertexts to each GPU kernel and to OpenFHE on the CPU, and compares every RNS word, the moduli, level, noise-scale degree, scaling factor and integer scaling factor. It then runs the GPU-only pipeline (search, relinearize, rescale, mask, rescale) and compares every stage with the OpenFHE chain, for three masks. 8 of 8 tests passed, for both presets at d = 16, 384, 768 and 1536, with no mismatch.

| Check | Result, every d and preset | Output shape |
| --- | --- | --- |
| Relinearize at level 0 | exact match | level 0, degree 2, 2 components x 3 towers |
| Rescale, level 0 to 1 | exact match | level 1, degree 1, 2 x 2 |
| Relinearize at level 1 | exact match | level 1, degree 2, 2 x 2 |
| Ciphertext multiply with relinearization, level 1 | exact match | level 1, degree 2, 2 x 2 |
| Rescale, level 1 to 2 | exact match | level 2, degree 1, 2 x 1 |
| GPU-only pipeline, every stage | exact match | |

## Score error of the GPU-only search

Max over all 8192 slots (4096 at compact) of |decrypted - (stored @ q) * mask|, GPU-only pipeline. "CPU" is the same steps from OpenFHE. Bound 1e-6, on `m0_depth2`.
