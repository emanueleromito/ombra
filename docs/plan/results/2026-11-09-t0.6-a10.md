# T0.6: encrypted filter mask on GPU search scores

- **Command:** `modal run modal_app.py::test_gpu --pytest-args "--expansion-large -k test_gpu_filter_mask"`
- **Commit:** `d92337b`
- **GPU:** NVIDIA A10 (Ampere, sm_86), Debug build
- **CUDA:** 12.6.3 image. Compiled for sm_80 and sm_86.
- **OpenFHE:** v1.6.1, openfhe-python 1.6.1.0 (pinned image)
- **Parameter set:** `m0_depth2` from `core/params/ckks_presets.json`, unchanged: HEStd_128_classic, ring dimension 16384, depth 2, scaling 50 bits, first modulus 60 bits, batch size 8192, FIXEDMANUAL, HYBRID (decision 0009)

## Pipeline

Synthetic seeded data, 8192 stored vectors, one run per d.

1. GPU query expansion (`ombra_expand_gpu`, exact RNS match with OpenFHE required).
2. GPU column-packed search over those leaves (`ombra_column_search`, exact RNS match required).
3. In OpenFHE: Relinearize, then Rescale (query x stored, 1 level); EvalMult with an encrypted 0/1 mask at level 1, then Rescale (mask, 1 level). The test asserts level 2 on the result.

Relinearize, Rescale and the mask multiply run on CPU: there are no GPU kernels for them yet. The CPU column is the same steps from the OpenFHE search result.
