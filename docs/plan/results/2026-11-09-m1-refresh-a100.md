# M1 refresh: T0.4 search harness and T1.3 end-to-end, on main

- **Commands:** `modal run modal_app.py::bench --task t0.4`, then `--task t1.3`, then `make results-pull`
- **Commit:** `aba6ddc` (main, after T1.4 and the T1.5 removal; batches B and C are not on main)
- **GPU:** NVIDIA A100-SXM4-40GB. **CUDA:** 12.6.3 image. **OpenFHE:** v1.6.1, openfhe-python 1.6.1.0 (pinned image)
- **Parameter set:** `m0_depth2`, unchanged
- **Timing:** T0.4: kernel only, median of 10 runs after 2 warm-ups. T1.3: 20 timed queries per case after 3 warm-ups, median per step, Release build, network excluded. One run of each, so one sample per machine.
- **Raw output:** `docs/plan/results/raw/results/t0.4-a100.json` and `t1.3-a100.json` (gitignored)

## Conclusion

**The gap with T1.4 is run-to-run variation, not code.** The same kernel measures 19.3 to 24.4 ms at d = 384 across three runs, and within 2% at d = 1536. Across runs, the T1.4 speedup is 1.29x to 1.46x, against the 1.49x to 1.54x measured in T1.4's own before-and-after run.

**End-to-end latency did not improve, and in this run it is 1.12x to 1.64x higher than the T1.3 run.** GPU steps are flat or faster. The increase comes from CPU steps whose code did not change: client decrypt is about 1.8x to 1.9x slower and reading the query about 2.2x slower. The likely cause is a slower host CPU on this Modal machine, but this run did not record the CPU, so that is not proven. Comparing the two runs, client encode and encrypt did not slow down, which leaves that explanation incomplete.

The T1.4 speedup barely reaches the total because the search kernel is a small part of a query: Stage 2 GPU is 3.5% to 8.1% of the total at 1M vectors, 20% searched, where client stage 2 is 63% to 78%.

## Limits

- One run per task, on one machine. The T1.3 file's figures are from a different machine, and the CPU model of neither was recorded.
- Batches B and C add upload checks that are not on this commit; they run once per upload and were not timed.
- The stored data is one real block plus device copies of it, as in T1.3.
