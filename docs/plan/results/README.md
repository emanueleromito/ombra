# Results

One Markdown file per benchmark run, named `YYYY-MM-DD-<task>-<gpu>.md` (for example `2026-11-10-t0.4-a100.md`).

Each file records: the command that produced it, the git commit, the GPU, CUDA and OpenFHE versions, the FHE parameter set, and the numbers in a table. Raw CSV or JSON output can sit next to it with the same name.
