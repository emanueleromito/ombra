# T0.2: CKKS CPU baseline

- **Command:** `modal run modal_app.py::test_openfhe --pytest-args=-s` (the `make test-openfhe` function, with pytest output shown), then `make results-pull`
- **Commit:** `3fed005`
- **Hardware:** Modal CPU-only container, no GPU. Requested `cpu=4.0`, `memory=8192`; `os.cpu_count()` reported 20.
- **CUDA:** not used
- **OpenFHE:** v1.6.1, openfhe-python 1.6.1.0 (pinned image)
- **Parameter set:** `m0_depth2` from `core/params/ckks_presets.json`: HEStd_128_classic, ring dimension 16384, depth 2, scaling 50 bits, first modulus 60 bits, batch size 8192, FIXEDMANUAL, HYBRID (decision 0009)
