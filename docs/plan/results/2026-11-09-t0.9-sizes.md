## Storage and ratio to float32

## Vectors that fit in A100 memory

A derived figure, from measured object sizes; nothing was allocated on a GPU for this table.

```
fixed  = 1 GiB scratch + automorphism keys + relin key + d x 786,432 B (one expanded query)
blocks = floor((42,429,251,584 - fixed) / (d x per_column_bytes + 524,288 B))
vectors = blocks x 8192
```

The 524,288 B per block is one level-1 score ciphertext held on the device (conservative: no mask, so larger than level 2). The 1 GiB scratch and the single expanded query are assumptions; a batch of queries needs more room (T0.7).
